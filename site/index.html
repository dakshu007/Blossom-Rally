Pit lane Q&A

Is it free?

Yes. The testing build is free to download and play.

Why do you need my email?

We send a one-time code to make sure a real racer is on the other end. It keeps the testing build out of random link-sharing and lets you come back for each Thursday build with the same email.

macOS says the app “can’t be opened”

It's a testing build that isn't notarized yet. Unzip it, then right-click (or Control-click) Blossom Rally and choose Open, then Open again. If it's still blocked, go to System Settings → Privacy & Security and click Open Anyway.

Windows shows “Windows protected your PC”

That's SmartScreen being careful with a new, unsigned game. Click More info → Run anyway. Unzip the whole folder first — the game needs the files next to the .exe.

When do updates come out?

Every Thursday. Come back here, verify with the same email, and download the latest build.

I didn't get the code

Check spam and promotions. Codes expire after a while — hit Resend in the download window to get a fresh one.
